# Simple Blog Layout Using Bootstrap 5

## Task 8 - Web Development Internship

This project is a responsive blog layout created using **Bootstrap 5 CDN**.

---

##Objective

To build a simple blog webpage including:
- Responsive Navbar
- Blog Cards
- Footer
- Bootstrap Grid System

---

##  Tools Used

- HTML5
- CSS3
- Bootstrap 5 (CDN)
- VS Code
- Browser

---

## Features

- Responsive Navigation Bar
- Bootstrap Grid Layout
- Card Components for Blog Posts
- Hover Effects on Cards
- Modern UI Styling
- Fully Responsive Design

---

##  Key Concepts Used

- Bootstrap CDN
- Grid System (row, col-lg-4, col-md-6)
- Utility Classes (my-5, g-4, text-center)
- Bootstrap Components (Navbar, Card, Button)
- Custom CSS Styling

---

## Responsiveness

- 3 cards on large screens
- 2 cards on medium screens
- 1 card on small screens
